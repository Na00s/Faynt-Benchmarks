# Faynt benchmark source

The initial suite evaluates Base and Expert; the expanded suite evaluates the reinforcement-learned Arena endpoints at 10M step 632 and 75M step 980. This repository contains their native runners, replay validation, result reporting and cloud execution code. See [Local benchmarks and cloud execution](docs/LOCAL_BENCHMARKS.md) for exact scope, commands, runtime contracts, historical metadata and required external inputs. The [evaluation runtime](evaluation/README.md) documents the Expert-to-Arena private zero-delay comparison, Arena versus Phillip, and native checkpoint loading for all six models.
